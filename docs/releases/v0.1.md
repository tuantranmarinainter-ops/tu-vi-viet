# Tử Vi Việt v0.1

Bản phát hành đầu tiên ngày 05/11/2026. Phiên bản package: `0.1.0`; nội dung luận giải tiếng Việt: `vi-natal-v2`.

## Chức năng

- Lập lá số với giao diện chính bằng tiếng Việt, nhập ngày dương/âm và lựa chọn lịch Việt hoặc lịch gốc.
- Chuẩn hóa giờ sinh dùng chung cho biểu mẫu, lịch sử và liên kết chia sẻ; có lựa chọn múi giờ, giờ đồng hồ/giờ mặt trời và quy tắc đổi ngày, tháng nhuận. Không tự lập lá số khi chưa biết giờ sinh.
- Hiển thị bản mệnh, đại hạn và tứ hóa lưu niên; lịch sử trên trình duyệt, chia sẻ URL, xuất JSON và in/lưu PDF.
- Luận giải 13 chủ đề bằng tiếng Việt; Tổng quan, Sự nghiệp, Tài chính, Tình cảm có bài mở rộng kèm căn cứ và nguồn khái niệm.
- Đọc dữ liệu v4 gốc theo năm, kiểm SHA-256 và cấu trúc lá số trước khi hiển thị; hỗ trợ xuất/nạp bản dịch theo mã nội dung. Không tự gọi API AI.

## Chạy ứng dụng

Cài Node 22.15+ trong nhánh 22.x hoặc Node >=24, sau đó chạy:

```sh
npm ci
npm run build
npm run start -- --port 3100
```

Mở http://127.0.0.1:3100/chart. Trên Windows có thể dùng `Chay-TuVi.cmd`; xem `README.vi.md` để cài runtime portable nếu cần. Runtime, dependency và cache dữ liệu không được đóng gói trong mã nguồn.

## Giới hạn

- Quy tắc an sao kế thừa repo gốc; chưa chứng nhận một trường phái Việt Nam cụ thể hoặc tự xác minh mọi lịch/múi giờ lịch sử.
- Luận giải tiếng Việt do ứng dụng biên soạn, chưa được chuyên gia thẩm định; bài đọc hiện tại là bản mệnh, chưa luận riêng từng đại hạn/lưu niên.
- Dữ liệu v4 bằng tiếng Trung, có năm sinh 1950–2026 và chỉ gắn khi cấu trúc tương thích. Không bao gồm thư viện phán đoán đóng hoặc backend AI của tác giả.
- Một số trang cổ thư/nghiên cứu vẫn giữ nguyên ngôn ngữ gốc.
